Yomitoki（よみとき・讀解）
個人用的多語言漫畫截圖翻譯閱讀工具

使用聲明
・本工具僅供個人閱讀理解。
・使用者須自行遵守各平台的使用條款與所在地的著作權法。
・翻譯結果不得散布，請只留在自己的電腦裡。
・Yomitoki 只處理你自己截下的畫面，不下載、不攔截、不還原任何網站上的圖片。

安裝完成後
・首次啟動精靈會下載翻譯需要的元件與模型（約 3～5 GB，需要網路）。
・翻譯透過你自己登入的 Claude Code 進行，會使用你的 Claude 訂閱額度。
・截圖不會離開你的電腦，只會把辨識出的文字交給 Claude Code 翻譯。
