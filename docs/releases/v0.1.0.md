# Yomitoki 0.1.0

第一個版本：在 Windows 上把**你自己截下的**日文漫畫頁，翻成嵌好繁體中文的圖來讀。
First release: turn Japanese manga pages **you capture yourself** into pages typeset in Traditional Chinese, on Windows.

## 需求 / Requirements

- Windows 10 或 11（64 位元）/ Windows 10 or 11 (64-bit)
- [Claude Code](https://docs.claude.com/en/docs/claude-code/overview)，並用 Claude 訂閱登入 / signed in with a Claude subscription
- 約 12 GB 可用空間（有 NVIDIA 顯示卡）或 6 GB（CPU 模式）/ about 12 GB free (NVIDIA GPU) or 6 GB (CPU mode)
- 建議 NVIDIA 顯示卡，4 GB VRAM 以上 / an NVIDIA card with 4 GB+ VRAM is recommended
- Google Chrome 116 以上（瀏覽器插件）/ Chrome 116+ for the extension

## 安裝 / Install

1. 執行 `Yomitoki-Setup-0.1.0.exe`。不需要系統管理員權限，預設裝到 `%LOCALAPPDATA%\Yomitoki`。
   Run `Yomitoki-Setup-0.1.0.exe`. No admin rights needed; it installs to `%LOCALAPPDATA%\Yomitoki`.
2. 首次啟動精靈會下載元件與模型（約 3～5 GB，10～30 分鐘），連接 Claude Code，引導安裝插件，最後試翻一張範例。
   The first-run wizard downloads the components and models (3–5 GB, 10–30 minutes), connects Claude Code, walks you through the extension, and translates a sample page.
3. 瀏覽器插件：到 `chrome://extensions` 開啟「開發人員模式」，按「載入未封裝項目」，選 `%LOCALAPPDATA%\Yomitoki\program\extension`。之後看漫畫時按 `Alt+Shift+Y`。
   Extension: open `chrome://extensions`, turn on Developer mode, click "Load unpacked" and choose `%LOCALAPPDATA%\Yomitoki\program\extension`. Then press `Alt+Shift+Y` while reading.

Windows SmartScreen 可能會警告「無法辨識的應用程式」，因為安裝檔還沒有程式碼簽章。確認 SHA-256 相符後，按「其他資訊」→「仍要執行」。
Windows SmartScreen may warn about an unrecognized app because the installer isn't code-signed yet. After checking the SHA-256, click "More info" → "Run anyway".

## 內容 / What's in 0.1.0

- 翻譯核心：文字偵測、OCR、擦字、直書嵌字（遵守中日韓標點禁則）。 / Detection, OCR, inpainting and vertical typesetting with CJK line-breaking rules.
- 透過你自己登入的 Claude Code 翻譯，不需要 API key；只送出辨識出的文字，截圖不會離開你的電腦。 / Translation through your own Claude Code, no API key; only recognized text is sent, screenshots never leave your computer.
- 作品記憶：詞彙表（待確認 / 已確定）、語氣規則、劇情摘要。 / Per-series glossary, tone rules and story notes.
- 介面：書架、作品頁、閱讀器（按住空白鍵看原文）、詞彙表、設定；夜讀模式；繁中 / English。 / Shelf, series page, reader, glossary, settings; night mode; zh-TW / English.
- Chrome 插件：一鍵截取畫面並顯示譯圖，或整話先存截圖再一起翻。 / One-key capture with the result in the side panel, or save pages to translate a whole episode later.
- 安裝檔與首次啟動精靈。 / Installer and first-run wizard.

## 已知限制 / Known limitations

- 只支援 Windows，而且目前只在一台 GTX 1650 的電腦上驗證過。 / Windows only, verified on one GTX 1650 machine so far.
- 只支援日文 → 繁中、頁漫。條漫與韓文在 0.2。 / Japanese → Traditional Chinese, page manga only. Webtoon mode and Korean are planned for 0.2.
- 插件沒有上架 Chrome 線上應用程式商店，需要手動載入。 / The extension isn't on the Chrome Web Store yet.
- 英文介面下，部分引擎錯誤訊息仍是中文。 / Some engine error messages are in Chinese even in the English UI.
- 誤加的頁面要到作品資料夾手動刪除。 / Pages added by mistake have to be deleted from the series folder by hand.

## 使用聲明 / Usage notice

本工具僅供個人閱讀理解。請遵守各平台條款與著作權法，翻譯結果不要分享或上傳。Yomitoki 只處理你自己截下的畫面，不下載、不攔截、不還原任何網站上的圖片。
For personal reading only. Follow each site's terms and copyright law, and don't share translated pages. Yomitoki only processes screenshots you take yourself; it never downloads, intercepts or reconstructs images from websites.
